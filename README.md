# Okara

Okara turns an authorized X voice or user-provided writing samples into five editable post drafts. It learns from explicit feedback and edits through visible, user-controlled Global and voice-specific preferences.

- **Live product:** [okara-eight.vercel.app](https://okara-eight.vercel.app)
- **Product architecture and reasoning:** [PRODUCT_README.md](./PRODUCT_README.md)
- **Detailed implementation plan:** [PLAN.md](./PLAN.md)
- **Execution and validation record:** [AGENT_TRACKER.md](./AGENT_TRACKER.md)

The product architecture document explains how voices are built, how prompts are assembled, how feedback becomes ranked memory, what is stored in Postgres, the security and cost controls, the main trade-offs, and the scalability path.
